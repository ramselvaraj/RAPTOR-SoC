## Overview

RAPTOR-SoC is a RISC-V based System-on-Chip project. This repository contains the
hardware design sources, verification environment, and supporting documentation.

## Repository Layout

```
RAPTOR-SoC/
├── docs/            # Documentation and assets (logo, diagrams)
├── rtl/             # RTL design sources
├── tb/              # Testbenches / verification
├── sw/              # Software (firmware, bare-metal, tests)
└── README.md
```
